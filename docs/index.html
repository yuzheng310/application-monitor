使用前，你可能想知道

真的不需要安装依赖吗？

完整 Release 包包含应用的运行环境、第三方包、浏览器和扩展，启动时不会执行安装命令或下载依赖。操作系统自身的桌面库和驱动由系统提供。请选择对应系统的完整包，而非 GitHub 的 Source code。

首次登录和之后的查询怎么完成？

软件使用独立内置浏览器，你需要在里面亲自登录招聘网站和处理验证码。之后会复用这个浏览器的登录状态。查询时需要联网，并保持内置浏览器打开。

可以直接在这个网页查询我的投递吗？

这里是公开介绍与演示网站。实际查询在你下载的软件里运行，使用本机浏览器登录状态；此网页不会读取或上传你的投递数据。

为什么某家公司会查询失败？

读取规则来自已适配的招聘页面。网站改版、未登录、没有可识别记录或额外验证可能导致失败；应用会保留上次成功结果。当前不自动遍历所有年份、分页或招聘类别，具体进度仍以官网和 HR 通知为准。

系统提示未知开发者怎么办？

发布包尚未进行商业代码签名。macOS 可在「隐私与安全性」中允许本次打开，Windows 可能显示未知发布者提示。完整说明和 SHA-256 校验文件见 GitHub Release，无需关闭系统安全功能。
